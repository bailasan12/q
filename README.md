## Render

المنتجات التي تُضاف من لوحة التحكم والطلبات والصور المرفوعة تُحفظ في SQLite وملفات محلية. لذلك يجب تشغيل الخدمة مع Persistent Disk حتى لا تختفي بعد كل نشر.

يوجد ملف `render.yaml` جاهز ينشئ قرصًا دائمًا بحجم 1GB ويربطه على `/var/data`، ويضبط `DATA_DIR` تلقائيًا. استخدم هذا الملف عند إنشاء الخدمة من Render Blueprint.

إذا كانت الخدمة موجودة مسبقًا، اضبط الإعدادات يدويًا:

1. أضف Persistent Disk إلى الخدمة.
2. اجعل Mount Path هو `/var/data`.
3. أضف متغير البيئة `DATA_DIR` بقيمة `/var/data`.
4. أعد نشر الخدمة.

مهم: لا تستخدم أكثر من نسخة Web Service مع SQLite وPersistent Disk، لأن القرص لا يُشارك بين النسخ. بدون Persistent Disk ستُفقد قاعدة البيانات والملفات المرفوعة عند إعادة إنشاء الخدمة.
